## Что нового

По сравнению с официальным **VTosters Lite** и **vkataxa 1.0.6** в текущей сборке:

### Музыка: «Моя волна» и импорт Spotify

- В музыкальном разделе появилась вкладка **«Моя волна»**: рекомендации на основе `audio.getRecommendations`, кэш, обновление очереди и play/pause-кнопка.
- Если VK не вернул рекомендации, используется fallback на Last.fm (`track.getSimilar` + поиск в VK).
- В настройках музыки можно выбрать источник рекомендаций: «Авто», «ВКонтакте», «Last.fm».
- Добавлен импорт плейлистов Spotify:
  - напрямую через OAuth, если у владельца Spotify-приложения есть Premium;
  - без Premium — через CSV-экспорт (например, Exportify): приложение ищет треки в VK, создаёт плейлист и умеет синхронизировать его повторным импортом;
  - импортированные CSV-плейлисты можно удалить вместе с VK-плейлистом.
- Оформление вкладки адаптируется под светлую/тёмную тему и акцент; кнопка запуска показывает play/pause.

### Удалённые сообщения

- Анти-удаление: удалённые сообщения остаются в чате, помечаются выбранным тегом, показываются полупрозрачными и получают красный кружок рядом с сообщением — как индикатор непрочитанного.
- Восстановление фото из удалённых сообщений: изображения сохраняются локально и возвращаются в сообщение.
- В просмотрщике удалённого фото появилась кнопка «Скачать», даже если оригинал уже удалён с сервера.
- Удалённые сообщения можно очистить для отдельного чата или группы: меню чата → «Очистить удалённые сообщения». Удаляются сохранённые маркеры, восстановленные фото и локальные копии удалённых сообщений.
- Сохранение фото удалённого сообщения в галерею, если исходное вложение уже недоступно.
- Удалённые сообщения теперь привязаны к локальному id сообщения и диалогу, поэтому одинаковые серверные `vk_id` в разных чатах больше не помечают чужие сообщения.
- Схема `deleted_msgs` обновлена без потери старых данных: добавлены `peerId`/`localId`, дубликаты удаляются, для новых записей действует уникальный индекс.

### Сообщения и производительность

- Кэш plain-text сообщений: повторные проверки шифрования при рендере списка пропускаются.
- Полупрозрачность удалённых сообщений применяется только при фактическом изменении alpha.
- Восстановление фото больше не делает повторные поиски в списке изображений и повторные чтения id вложения.
- Вложенные сообщения расшифровываются только у удалённых сообщений; при выключенном анти-удалении обработка пропускается, поэтому история грузится быстрее.
- Исправлены лишние сетевые запросы при копировании фото, утечки ответов Google Translate и падение при отсутствии выбранного переводчика.
- Исправлен радиус круглой обрезки изображений для неквадратных картинок.
- Исправлен сброс SOCKS-порта при отключении прокси.
- Ошибка загрузки превью плейлиста больше не выбрасывает исключение из фонового колбэка.

### Обновления и надёжность

- Автообновление и ручная проверка обновлений теперь используют репозиторий `cataxaract/vkataxa`, а не архивный upstream.
- Проверка сравнивает commit установленной сборки с commit релиза через GitHub compare: не предлагает откатиться на более старую версию и не показывает одно и то же обновление повторно.
- Пропущенный релиз запоминается, а в диалоге обновления есть кнопка «Не сейчас».
- APK для обновления выбирается по имени, HTTP-ответы закрываются, `DownloadManager` receiver корректно отменяется.
- Краш-репортер использует immutable `PendingIntent`, сам не падает при обработке падения и всегда передаёт управление исходному обработчику.
- Логи падений на Android 10+ сохраняются через MediaStore в `Download/VK/logs/com.vtosters.lite`.
- Вызовы AppCenter не выполняются, пока SDK не запущен.
- Проверка обновлений больше не скрывается в сборках, подписанных debug-ключом; обновление устанавливается только поверх сборки с той же подписью.

### Сборка

- Windows-сборка использует `rclass_regenerator.bat` и выполняет `zipalign` перед подписью, если утилита доступна.
- `version.properties` генерируется на каждой сборке и попадает в APK.
- Убран жёстко заданный release AIDL source dir, из-за которого beta/rc падали с дубликатом `ILibVkxService`.
- `APPCENTER_KEY` добавлен в `defaultConfig`, поэтому debug-вариант тоже компилируется.
- CI обновлён на `actions/checkout@v4`, `actions/setup-java@v4` (Temurin 17) и `actions/upload-artifact@v4`.

## Функциональность

- Возможность вернуть старый дизайн ВКонтакте.
- Нет рекламы и ограничений музыки.
- Интеграция с <a href="https://vkx.app/">VKX</a> и <a href="https://www.last.fm/">Last.FM</a>.
- «Моя волна» с рекомендациями VK и fallback на Last.fm, импорт плейлистов Spotify через CSV или OAuth.
- Кастомизация и фильтрация ленты новостей.
- Кеширование и скачивание треков.
- Редактор нижней панели.
- Скрытие активности в сообщениях и офлайн-режим.
- Стикеры из Telegram.
- Отключение редиректа через `away.php`.
- Сторонние прокси (в том числе для пользователей из Украины).
- Анти-удаление сообщений и восстановление удалённых фото.
- Шифрование переписки и перевод сообщений.
- Эксклюзивные функции и галочки для поддержавших разработку.
- Глобальная оптимизация клиента: удалены сторонние библиотеки рекламы, аналитики и метрики, добавлены заглушки для рекламных запросов.

Список функций может отличаться от официального VTosters Lite.

## Настройки

Ниже — где искать функции, которые добавлены или доведены в этом форке.

### Музыка

**Настройки → Музыка**

| Пункт | Что делает |
|---|---|
| Источник рекомендаций | «Авто» сначала пробует VK, затем Last.fm; «ВКонтакте» и «Last.fm» фиксируют источник. |
| Импорт из Spotify | Открывает экран импорта: OAuth для Premium или CSV без Premium, список плейлистов, синхронизация и удаление. |

### Удалённые сообщения

**Настройки → Активность → Анти-удаление сообщений**

| Пункт | Что делает |
|---|---|
| Пометка удалённого сообщения | Выбирает тег, который добавляется к сохранённому сообщению. |
| Оставлять удалённые сообщения | Включает анти-удаление. Пока выключено, зависимые пункты недоступны. |
| Восстанавливать фото | Сохраняет и возвращает изображения из удалённых сообщений. Включено по умолчанию. |
| Выделять удалённые сообщения | Показывает сохранённые сообщения полупрозрачными. Включено по умолчанию. |

Очистка только одного чата или группы: меню чата → **«Очистить удалённые сообщения»**. Действие удаляет сохранённые маркеры, восстановленные фото и локальные копии удалённых сообщений этого чата; обычные сообщения не затрагиваются.

### Сообщения

**Настройки → Сообщения**

- Обои чатов.
- Голосовые сообщения.
- Writebar в стиле iOS.
- Переводчик: язык, сервис, автоперевод и перевод всех сообщений.
- Отключение бизнес-уведомлений.
- Отправка сообщения по Enter.

### Активность и приватность

**Настройки → Активность**

- Анти-удаление сообщений.
- Онлайн и офлайн-режим.
- DNR (не отмечать прочитанным) и DNT (не показывать «печатает»).
- Истории, прослушивания, скриншоты, `away.php`.
- Скрытие информации об устройстве.
- Экспериментальная альтернативная загрузка сообщений (`batchmessages`).

### Обновления

**Настройки → Обновления**

- «Проверить обновления» — ручная проверка последнего релиза.
- «Автообновления» — проверка при запуске приложения, но не чаще одного раза в 12 часов.
- Если релиз уже пропущен или обработан, авто-проверка не показывает его повторно; ручная проверка работает всегда.

### О модификации

**Настройки → О модификации**

- «GitHub» — исходный код и репозиторий `cataxaract/vkataxa`.
- «Релизы» — скачивание последней версии.
- «FAQ» — README проекта.
- «Сообщить о баге» — Issues этого форка.
- «Открыть коммит» — commit установленной сборки в `cataxaract/vkataxa`.

**Настройки → Для разработчиков → Запись логов в файл**

На Android 10+ логи пишутся через MediaStore в `Download/VK/logs/com.vtosters.lite`; на более старых версиях — по тому же пути через обычный файл.

## Отладка приложения

Для отладки через <a href="#"><img src="https://i.imgur.com/cPvvFDP.png" align="center" width="20" height="23"/></a> Android Studio измените значение в `/smali/AndroidManifest.xml`:

`android:debuggable="false"` ➝ `android:debuggable="true"`

- Для дополнительных логов включите **[Режим разработчика]**.
- Для просмотра SSL-трафика **отключите** **[SSL Pinning]**.
- Для логгирования запросов к API включите **[Логгирование API]** <sup>(работает только с внутренним логгером)</sup>.
- Для записи логов в файл включите **[Запись логов в файл]**.

После включения запись начинается сразу; файлы появляются в `Download/VK/logs/com.vtosters.lite`. При следующем запуске приложение может сохранить логи в [**Документы** ВК](https://vk.com/docs).

## Разработка

Для навигации по декомпилированному коду используйте [jadx](https://github.com/skylot/jadx) или [Fernflower](https://github.com/fesh0r/fernflower). Для индексации в Android Studio — [dex2jar](https://github.com/pxb1988/dex2jar).

- Декомпилированный код клиента: `/smali`
- Исходники модификации: `/app`
- Скрипты, apktool, apksigner и framework: `/scripts`
- Готовый APK: `/build-output`
- Сгенерированные из `.dex` библиотеки: `/app/libs`

При чистой перекомпиляции `.dex` → `.jar` часть индексации может сломаться; правьте вручную (например, модификаторы `private`/`public`).

### Зависимости

- [JDK](https://adoptium.net/temurin/releases/) 17 (минимум 14).
- [Rust](https://www.rust-lang.org/learn/get-started) с Android-таргетами:
  `rustup target add aarch64-linux-android armv7-linux-androideabi`
- Android SDK: platform 32 и build-tools 32.0.0.
- Android NDK 25.2.9519653.

`native-effects` собирается на Rust. Если меняете `native-effects/src/lib.rs`, пересоберите `.so` для обеих ABI и обновите файлы в `smali/lib/` — иначе APK продолжит использовать закоммиченную библиотеку.

### R.java и ресурсы

`R.java` генерируется из `smali/res/values/public.xml` скриптом `rclass_regenerator`. На Windows теперь вызывается `.bat`-версия. Если добавляете новые ресурсы, на которые ссылается Java-код, не забудьте перегенерировать `R.java`.

## Сборка

Задачи Gradle:

```bash
./gradlew buildVTLDev       # собрать и подписать APK
./gradlew buildFastVTLDev   # быстрый цикл: только dex в уже собранный APK (без apktool)
./gradlew buildVTLRelease   # release-вариант
./gradlew buildAndInstallVTLDev
./gradlew buildAndLaunchVTLDev
./gradlew prepareDexForMergeDev  # [для разработчиков] подготовить dex в smali/
./gradlew exportDexDev           # [для разработчиков] выгрузить dex из собранного APK
```

Типы сборки: `Dev`, `Beta`, `Release`.

Проверка изменений:

```bash
./gradlew test
./gradlew :app:compileDevJavaWithJavac
./gradlew :app:assembleDev
```

Тестовых классов в проекте пока нет, поэтому `test` в основном проверяет компиляцию и конфигурацию вариантов.

`build-output/VTLite.apk` подписывается `scripts/debug.keystore`. Обновление поверх установленной версии сохранит данные только при той же подписи и том же package; не меняйте `com.vtosters.lite` и не пересоздавайте keystore.

### CI

GitHub Actions собирает APK через `prepareDexForMergeDev`, apktool, zipalign и apksigner, после чего выгружает APK и `RELEASE_NOTES.md`. История изменений ведётся в корневом `RELEASE_NOTES.md`; `build-output/RELEASE_NOTES.md` — копия для артефакта и в git не попадает.

## Известные ограничения

- Подгрузка старых сообщений, которых нет в локальной БД, ограничена `messages.getHistory`: максимум 200 сообщений за запрос и скорость ответа VK. Уже загруженная история читается из SQLite.
- Анти-удаление хранит удалённые сообщения и фото локально; при полной пересинхронизации с сервером часть данных может исчезнуть.
- Автообновление работает только для сборок с той же подписью. Debug-ключ находится в репозитории, поэтому не используйте такие APK там, где нужна защита от подмены.
- Старые записи `deleted_msgs` без `localId` сопоставляются по серверному id; после повторного удаления сообщение получает локальный id.
- Перевод в legacy-кэше выполняется синхронно; вынос перевода в фон — отдельная задача.
- Прямой импорт Spotify через OAuth требует Premium у владельца Spotify-приложения из-за политики Spotify; без Premium используйте CSV-импорт.
- Last.fm fallback зависит от доступности API и может уступать VK по покрытию редких треков.
- CSV-импорт берёт имя плейлиста из имени файла; повторный импорт файла с тем же именем синхронизирует VK-плейлист.
